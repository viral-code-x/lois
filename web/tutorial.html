LOIS

LANGUAGE OPERATED on IS

LOIS is a simple, human-readable programming language designed to make programming and mathematics explicit and easy to understand.

LOIS is made for beginners. It keeps programming concepts recognizable and follows clear rules instead of hiding everything behind magic.

Basic Syntax

LOIS programs are written as a sequence of statements. Newlines normally separate statements.

name is "Afnan"
age = 15

if age >= 13
then output is "Teenager"

Comments

Single-line comments

note: this line is ignored

output is "Hello"

note: is case-insensitive.

Multi-line comments

[
This entire section
is ignored by LOIS.

Output

LOIS has two main output forms:

output is ...
output = ...

output is

output is prints something directly or prints a stored value.

output is "Hello World"
output is 12
output is "1 + 2"

The last example prints 1 + 2, rather than calculating it.

output =

output = evaluates an expression before printing it.

output = 1 + 2
output = (10 + 5) * 2

Output:

3
30

Functions

The primary function syntax is:

square is function of x * x

This creates a function named square with parameter x.

Calling functions

Function calls always use parentheses.

square is function of x * x

Output:

25

Multiple parameters

add is function of x + y

output = add(3, 6)

Output:

9

Functions in expressions

square is function of x * x

Output:

35

String functions

name is "Alice"

Alternative function syntax

Returns

Functions can explicitly describe their result using returns.

square function x it returns x * x

The expression after returns is the function result.

Nesting and then

LOIS does not use indentation to determine nesting.

Nested structures use then:

The Core Idea

The most important distinction in LOIS is is versus =.

name is "Alice"

stores text.

age = 15

stores a number.

output is name

prints a value directly.

output = age + 5

evaluates an expression and prints the result.

Functions follow the same readable structure:

square is function of x * x

square(5)

And control structures use then rather than indentation.
